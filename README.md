# ALUNA — One Page

Sitio web de ALUNA: cuadros en punto de cruz y blusas tejidas a mano.
Hecho a mano con HTML5 y CSS3 (sin frameworks), fiel al diseño de Figma.

## Estructura
- `index.html` — página (semántica, accesible, nombres BEM) y un pequeño script (menú, scroll-spy, parallax, carruseles).
- `styles.css` — estilos.
- `img/` — imágenes y capas exportadas de Figma.

## Cómo verlo
Abre `index.html` en el navegador.

## Publicar en GitHub Pages
1. Sube estos archivos a un repositorio (`index.html` en la raíz).
2. Settings → Pages → Source: `main` / root.

## Notas
- Escritorio (≥1024px): composición exacta del diseño con parallax. Menos de 1024px: diseño fluido.
- Fuentes: Google Fonts (Kanit, Caveat).
